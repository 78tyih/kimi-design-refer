# Kimi Design Refer

This skill is an aesthetic reference and routing layer, not an official Kimi brand kit and not a campaign-frame copier.

## Design equation

`quiet field + bounded evidence system + technical hierarchy + visible process + restrained anomaly`

## Task modes

Route to one primary medium:
- `web-ui`
- `ppt-pdf`
- `poster-social`
- `infographic`
- `motion`
- `review-only`

Read `references/medium-router.md`, then the matching medium file.

## Style families

Read `references/style-families.md` and choose exactly one primary family.

Read `references/zine-editorial-extension.md` whenever a zine family is requested or a Kimi × Zine blend is useful. The seven Kimi families remain the core system; the five zine families are an editorial extension.

A secondary family may influence at most 20% by default. For an explicit Kimi × Zine hybrid, follow the intensity rules in `zine-editorial-extension.md`. Never average all families together.

## Composition

Read `references/composition-recipes.md` and select one dominant recipe. Prefer semantic fit over novelty.

## Shared rules

Always apply:
- `references/philosophy.md`
- `references/design-dna.md`
- `references/typography-color.md`
- `references/originality-boundaries.md`
- `references/quality-gate.md`

Use `tokens/kimi.tokens.json` when machine-readable tokens help.

## Priority

1. meaning / content accuracy
2. composition and negative space
3. family identity
4. typography hierarchy
5. texture and atmosphere
6. decorative detail

Never sacrifice readability or exact facts to imitate a visual mood.

## Core behaviors

Prefer one quiet field, one bounded evidence cluster, procedural geometry, large negative space, micro-annotations, precise geometry with local material imperfections, and scientific/editorial framing.

Avoid generic blue-purple SaaS gradients, glassmorphism as the main idea, glowing brains, humanoid robots, holograms, generic node networks, cinematic starfields, heavy luxury-metallic 3D, equal card grids, and over-explaining with labels.

Random scrapbook distress, tape/sticker clutter, or unjustified torn-paper effects are not allowed unless the Zine Editorial Extension is explicitly active.

## Medium contracts

### Web UI
Return or implement selected family + recipe, visual direction, token choices, hierarchy, interaction notes, and usable implementation.

### PPT / PDF
Return or implement document visual thesis, page families, typography/data hierarchy, image treatment, and consistency rules.

### Poster / Social
Return or implement one imageable proposition, family + recipe, focal object, title placement, negative-space target, and final image prompt when an image model is used.

### Infographic
Return or implement exact content hierarchy, semantic layout, editable/vector-first structure when possible, and restrained visual framing.

### Motion
Return or implement visual state sequence, motion verb, tempo, transformation logic, loop/transition behavior, and family fidelity in motion.

### Review only
Score against `references/quality-gate.md`, identify the three biggest misses, and propose the smallest repairs first.

## Originality boundary

Never use Kimi/Moonshot logos unless the user supplies authorized assets and explicitly requests their use. Do not reproduce a known Kimi campaign frame, proprietary illustration, exact lockup, or page composition. Translate the user's own subject into the higher-level visual grammar.
