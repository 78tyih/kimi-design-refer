# Taste Profile

This file describes the default aesthetic biases of this Design Rules Library.

It is not a hard constraint. User requirements, brand rules and medium usability always take priority.

## Preferred qualities

### 1. Premium through restraint

Prefer designs that feel confident because they are edited, not because they are visually expensive.

Signals:

- fewer but stronger elements;
- controlled whitespace;
- careful typography;
- precise image placement;
- low decorative noise.

### 2. Intelligence should look observable

For technology, AI, trading, finance and research subjects, prefer visual languages that show:

- evidence;
- calibration;
- measurement;
- comparison;
- indexing;
- simulation;
- state transitions;
- documented process.

Avoid vague "AI magic" imagery.

### 3. Editorial + technical over generic SaaS

Prefer:

- editorial spacing;
- serif / mono / neutral sans combinations with clear jobs;
- evidence fragments;
- research-atlas logic;
- restrained diagrams;
- thoughtful asymmetry.

Avoid defaulting to:

- glass cards;
- blue-purple gradients;
- glowing brains;
- generic node networks;
- feature-card grids without narrative hierarchy.

### 4. Real trading / research texture when relevant

For trading and finance work, prefer meaningful visual material such as:

- real chart structure;
- order-flow / market data fragments;
- rules and payout evidence;
- comparison tables rendered cleanly;
- terminal / research context used sparingly.

Do not use decorative candlestick charts merely to signal finance.

### 5. Controlled imperfection is welcome

When the family supports it, allow:

- scan grain;
- print softness;
- dither;
- slight misregistration;
- graphite / ink texture;
- photocopy artifacts;

But keep layout logic precise.

The preferred tension is:

```text
precise structure
+ imperfect material surface
```

### 6. Strong preference for one visual thesis

A page or poster should usually be describable in one visual sentence.

Examples:

```text
A rule-change document behaves like evidence in a forensic proofboard.
```

```text
A market simulation exists inside one bounded observation window.
```

```text
A tiny payout record floats like an archived research specimen.
```

## Default avoid list

Unless the brief explicitly calls for them, avoid:

- generic corporate stock imagery;
- overly friendly illustration systems;
- kawaii / cartoon language;
- cyberpunk neon;
- excessive 3D gloss;
- dashboard chrome in non-dashboard contexts;
- decorative microtext with no semantic role;
- excessive rounded cards;
- heavy gradients used as atmosphere;
- visually loud CTAs in institutional / research work.

## Bias hierarchy

When two directions are equally valid, prefer:

```text
specific > generic
structured > decorative
editorial > templated
observational > magical
quiet > loud
real evidence > invented tech motifs
```
