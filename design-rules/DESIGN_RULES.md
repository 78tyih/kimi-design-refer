# Universal Design Rules

These rules apply **before** any specific visual system such as Kimi, Zine, Linear, Stripe, Nothing or HTX.

They are style-agnostic. A visual family may add constraints, but it should not violate these foundations unless the user explicitly requests an experimental exception.

## 1. One communication thesis

Every artifact needs one primary communication job.

Before designing, reduce the brief to one sentence:

```text
This design should make the viewer understand / feel / do ______.
```

A page may contain many facts, but it should not contain many competing theses.

## 2. Hierarchy before decoration

Resolve these in order:

1. what is primary;
2. what is secondary;
3. what is evidence;
4. what is annotation;
5. what is decoration.

Never use decorative intensity to compensate for weak hierarchy.

## 3. One dominant visual event

Prefer one dominant focal system per viewport / page / poster.

Secondary elements may support it, but should not compete at the same visual weight.

For dense interfaces, the dominant event can be a functional region rather than an illustration.

## 4. Negative space is structure

Empty space is not leftover space.

Use it to:

- isolate hierarchy;
- control reading order;
- create rhythm;
- distinguish evidence from commentary;
- increase perceived confidence and restraint.

Do not fill empty regions merely because they look unused.

## 5. Evidence before ornament

When the brief contains real data, rules, product behavior, comparison or proof, use that information as visual material before inventing decorative motifs.

Preferred order:

```text
real evidence
→ semantic diagram
→ meaningful metaphor
→ decorative motif
```

## 6. Text fidelity

If text must be exact, readable or legally / commercially important, render it with real typography whenever possible.

For web, slides, PDFs and infographics:

- keep important copy as HTML / SVG / vector / editable text;
- do not rely on image models for long paragraphs or exact numbers;
- use generated imagery as visual support, not as the source of truth.

## 7. Medium truth

Design for the actual medium.

- Web must remain usable and responsive.
- PPT/PDF must preserve reading order and exact copy.
- Posters may sacrifice density for a stronger proposition.
- Infographics prioritize semantic accuracy.
- Motion needs temporal hierarchy, not just animated decoration.

Do not make a website behave like a poster if it harms usability.

## 8. Color discipline

Define the role of color before choosing colors.

Possible roles:

- structure;
- status;
- emphasis;
- identity;
- anomaly;
- atmosphere.

A color should not serve all roles simultaneously.

When a system uses a chromatic accent, keep the rest of the palette quiet enough for that accent to remain meaningful.

## 9. Typography has jobs

Assign typography by function:

- display / thesis;
- body / explanation;
- annotation / metadata;
- numeric / data;
- code / technical state.

Avoid adding typefaces merely to create visual variety.

## 10. Repetition creates systems

Repeat rules, not identical compositions.

A coherent system should repeat:

- spacing logic;
- type hierarchy;
- color behavior;
- annotation grammar;
- component logic;
- motion behavior.

But each output should still respond to its own content.

## 11. Process should be visible when useful

For analytical, technical and research-oriented work, show traces of reasoning when they add meaning:

- measurement;
- comparison;
- indexing;
- state change;
- trajectory;
- calibration;
- simulation;
- annotation;
- transformation.

Do not add fake technical detail purely to look intelligent.

## 12. Restraint beats visual averaging

Do not mix every interesting reference into one artifact.

A strong result usually has:

```text
1 primary design system
+ 0–1 extension system
+ medium-specific adaptation
```

If more than two systems are required, one must clearly dominate and the others should contribute only narrowly defined traits.

## 13. Originality boundary

Learn visual grammar, not source identity.

Do not copy:

- exact campaign compositions;
- proprietary illustrations;
- logos without authorization;
- source text or signatures;
- distinctive lockups;
- sample-specific residue.

Translate the grammar into the user's own subject matter.

## 14. Accessibility and readability

Aesthetic restraint is not permission to reduce legibility.

Check:

- contrast;
- minimum readable type size;
- chart labels;
- interactive affordances;
- keyboard / touch behavior for UI;
- logical content order;
- color-independent status cues where relevant.

## 15. Final reduction pass

Before returning a design, ask:

```text
What can be removed without losing meaning?
```

Remove redundant borders, labels, icons, effects, colors, repeated messages and decorative micro-detail before adding anything new.
