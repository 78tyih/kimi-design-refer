## Color logic

Core system:

- black / charcoal / soft white / gray;
- cool lab neutrals where appropriate;
- accent color acts as punctuation rather than atmosphere.

Zine extension:

- restrained paper / grayscale base;
- one visible high-chroma anchor.

## Typography logic

Use type by job:

- modern sans for primary utility and clean declarations;
- editorial serif for research / index / statement contexts;
- mono for metadata, coordinates, state, evidence and technical labels;
- pixel type only when the selected family requires it;
- glyph display type only when typography is the visual event.
